# 🍽️ Restaurant App

Aplicación web interactiva diseñada para la gestión eficiente de pedidos, mesas y menús en un entorno de restaurante. Este sistema permite registrar órdenes de manera rápida, vinculando el número de mesa y la hora del servicio con los productos disponibles en el menú.

---

## 🚀 Características Principales

* **Gestión de Órdenes:** Creación de pedidos especificando el número de mesa y la hora exacta de la orden.
* **Carga Dinámica del Menú:** Sincronización en tiempo real con una base de datos local mediante `json-server`.
* **Control de Conexión:** Sistema de avisos integrado para notificar al usuario en caso de que el servidor backend no esté activo en el puerto correspondiente.
* **Interfaz Intuitiva:** Diseño limpio y adaptado para agilizar la atención en el área de servicio o caja.

---

## 🛠️ Tecnologías Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript (Vanilla).
* **Backend / Base de Datos:** `json-server` (simulación de API REST con un archivo `db.json`).
